# Research memory and generated programs

This extends the fixed capability-selection lane. It does not establish unrestricted self-improvement or hosted model training.

## What changes actual conversation

- A scheduled read-only job collects excerpts from the existing approved primary-source list (versioned Transformers.js documentation and arXiv AI abstracts). No user conversations enter research.
- Another read-only job independently fetches those sources again and checks exact title/excerpt/provenance agreement. It does not certify scientific claims or call an abstract a fully read paper.
- A separate publisher merges validated cards into a bounded 24-card active archive. Changed content advances the knowledge generation; unchanged documents do not manufacture improvement. Historical runs remain in Git.
- At query time the app selects at most three relevant cards and supplies their text as untrusted reference data, with source URLs and checked dates. The UI retains those source links with conversation history. Irrelevant prompts receive no retrieved excerpts. Citations show supplied references, not a guarantee that every generated sentence is entailed.
- Learned artifact reads are fixed public URLs, size limited, timed out, schema checked and hash checked. Healthy loaded artifacts survive failed refreshes. A fresh process can inherit accepted artifacts.

## Generated programs, not feature switches

The external anonymous model proposes a new expression tree plus a falsifiable hypothesis. Candidate values are data. The trusted interpreter permits rational addition, subtraction, multiplication and division only, with 48 nodes, depth 8, bounded numeric input and intermediate sizes. There is no eval, JS execution, network, filesystem, credential, validator edit or self-promotion operation.

Current trusted task contracts are percentage, discounted amount, three-value mean and rectangle area. This task space remains finite. New contracts require a separately reviewed PR. Programs can vary and simplify within the grammar; after every task is covered, only equally correct programs with fewer nodes can replace their parent. NO_GAIN is an ordinary result, not a failed product.

After freezing the candidate hash, a separate job creates 64 new samples including boundary cases. Python Fraction supplies the oracle; the actual JS interpreter executes the candidate. All 64 must agree. The publisher recomputes the expected sample set and the adoption decision, checks the current parent, and writes only fixed data paths. The runtime also checks oracle agreement before loading the program. Runtime failures quarantine the artifact and use ordinary chat; invalid refreshes preserve the previous healthy version. Existing dialogue-generation rollback remains in place.

This measures correctness of a narrow generated program and added task coverage. It is not a comparison against general model intelligence, independent external replication or evidence of RSI.

Examples after the corresponding program is adopted:

- `1000円の20%`
- `1000円の20%引き`
- `平均: 1, 2, 4` (exact rational output can be `7/3`)
- `長方形 2.5 × 3 の面積`
- In a continuing conversation, prefix with `計算:` so contextual questions keep the model path.

## Free operation and limits

Public standard GitHub runners perform bounded jobs every six hours and after a verified production release. Scheduled execution can be delayed or skipped; the UI shows actual recorded outcomes. Render is a free web service and can sleep/restart; no artificial keepalive is introduced. The API never embeds a user key. GitHub uses its existing ephemeral job token only in the isolated data publisher. No paid fallback exists. One provider-recovery attempt after 35 seconds is allowed during proposal generation; errors are recorded and cannot become passing evidence.

The external chat model still has unchanged weights. Partial model-learning experiments and proposed application source changes remain separate evidence lanes, with their existing hold/review gates. Physical iPhone testing, permanent availability, unrestricted app rewrites and guaranteed continuous intelligence growth remain unfulfilled. The original full-project completion is still EXPERIMENTAL_PARTIAL.
