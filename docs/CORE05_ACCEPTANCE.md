## Authorization and residual risks

The generator only proposes changes to five initial application files; this is a versioned pilot search space, not a final intelligence boundary. The publisher can write the data branch and generated candidate branches, not merge or deploy them. A separate, substantively justified improvement protocol is still needed before broad source candidates can be promoted automatically. Public regression tests can be gamed and may miss defects. Docker shares the host kernel; container isolation is not a proof of zero vulnerabilities. Validators share author, contract and infrastructure. The history keeps 24 recent decisions for prompting; older immutable record files remain in Git. Hashes provide tamper evidence, not protection against a privileged owner rewriting all history.
