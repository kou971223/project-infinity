# Project ∞ Core 0.4

**公開モデルを端末内で動かす会話画面と、別系統の限定研究・実学習実験です。Project ∞全体の完成や汎用的な自己進化の実証ではありません。**

## 使い方

サイトを開き「端末内AIを起動」を押します。最初に約500MBのモデルを取得するためWi-Fiを推奨します。GPUで起動できない場合は「CPUで起動」を使います。起動後は日本語で会話できます。入力文字は16px、履歴はこのブラウザ内に保存します。端末の互換性・空きメモリによって利用できない場合があります。

この経路は有料推論APIを使用しません。通信料金・端末の電力までゼロになる保証ではありません。旧Flootアプリは別システムです。

## 今回の研究処理

- 元の限定データフロー言語による応答抽出コードの合成、隔離実行、固定基準による検証・採用・復元。
- GitHub Models依存を廃止。GitHub公式資料では2026-07-30に終了しているため、そのAPIを稼働済みとは扱いません。
- 公開Qwen2.5-0.5B-Instructを固定リビジョンでCPU実行し、コード候補を生成します。モデル出力はコードとして直接実行せず、厳密な構造検査を通すデータとして扱います。
- 学習済みモデルの最終正規化重みだけを実際に更新し、訓練前の重みと比較する実験を実装。チャットへの学習済み重み反映はありません。
- 評価結果がFail/Unknownなら合格扱いにしません。最初の実行では学習処理は動作しましたが効果量基準未達、コード候補は形式違反で棄却しました。

## 自動実行

標準の公開リポジトリGitHub Actionsで、限定コード研究は毎時17分、CPU学習実験は6時間ごと47分に設定。遅延・停止・サービス制約があり、24時間連続計算を保証しません。実行ログと `research-records` ブランチの公開実験記録を確認してください。私的な会話はここへ保存しません。

## 実行・検証

```sh
npm test
python3 -m unittest discover -s test -p 'test_*.py' -v
npm run verify:cycle
npm run verify:oracle
npm start
```

Node22以上、通常のWebサーバーには追加npm依存なし。研究用Python環境は専用Actions内にだけ構築します。モデルはApache-2.0の公開重み、リビジョン固定・remote code無効です。

`/` 会話画面、`/lab` 限定コード比較、`/health` ビルド状態、`/api/free/status` 公開研究結果。旧有料API経路 `/api/chat` は無効です。
