# Project ∞ Core 0.8

サイトを開き、入力して送信します。会話モデルのダウンロード、API Key、Secret Key、有料推論設定は不要です。

本番: https://project-infinity-core.onrender.com

## 会話

- 確認済みの Pollinations 匿名エンドポイントを Render 経由で使用。POST 本文で会話を送信し、URLには入れません。公式匿名枠の15秒間隔に対し、サーバー側で外部推論を直列化し、前の応答完了から16秒以上空けます。
- `openai-fast` は提供元の一覧・応答で GPT-OSS 20B (OVH) と報告されています。重みの独立確認や一般的な性能保証ではありません。
- 過去の `openai` 指定は同じ匿名モデルの別名です。モデルが高性能化したと主張しません。
- 会話文の外部送信は画面下部に明記。提供元の保存条件・匿名枠の継続をアプリ側では保証できません。認証や課金が必要になった場合はエラーで停止します。
- 複数会話・履歴切替・再読み込み・新しい会話・停止・失敗再試行・JSON書き出し。履歴はこのブラウザのみ、50会話/各200メッセージまで。自動クラウド同期なし。保存失敗を表示します。ブラウザデータ消去で失われます。
- 推論コンテキストは直近最大8メッセージ/14,000文字。履歴全体をモデルに送信するわけではありません。
- iPhone向け16px入力、動的画面高、セーフエリア、320/390/430px表示検証。実機iPhoneのメモリ・キーボード・Safari状態は別途検証が必要です。

## 研究と権限

`研究記録` から各工程の実際の判定・時刻・世代を確認できます。

1. 固定の小さな命令言語でコード候補を合成し、独立した参照実装・新しい確認ケースで評価。限定モジュールのみ採用、回帰時はRollback。現在の外部応答抽出にも接続しています。
2. 公開コード・文献メタデータを入力とする研究。新しい無料・キー不要のコード提案工程は6時間ごと。Candidateを固定し、別ジョブのネットワークなしDockerでbaseline/candidateを比較。テスト成功だけでは一般コードを採用せず、レビュー待ちとして保存します。
3. 公開Qwen2.5-0.5Bを**GitHub ActionsのCPU研究専用**に使用する既存の部分重み学習実験。iPhoneでは実行しません。2 seedの固定条件で採否判定、受理重み・parent hash・世代・過去失敗を公開データブランチに保存。第3世代で固定上限となり保留中。評価基準を緩めて再開しません。
4. Knowledge Archiveは `research-records` ブランチ。会話履歴は公開しません。候補にGitHub書込み、Validator改変、基準変更、main更新権限はありません。

研究用の学習重みは外部会話モデルに反映できません。第三者モデルの重み変更権限はありません。独立した処理・Python参照評価と、外部研究者による独立再現は別です。

## 無操作時

既存の公開GitHubリポジトリの標準無料runnerで、開発・研究に必要な有限ジョブを定期実行。Renderのスリープ回避pingはしません。Renderは無通信15分で休止し、次のアクセスで起動します。スケジュール遅延・停止・無料枠上限により常時稼働は保証されません。

GitHub Actionsのアーカイブ用ジョブだけがGitHub自動発行の短期認証を使用します。利用者がAPI/Secret Keyを取得・登録する工程はなく、候補、ブラウザ、コードへ実値を埋め込みません。これを含む全認証も禁止する解釈なら、GitHubへの自動保存・採用は実現できません。

## 検証

```sh
npm test
python3 -m unittest discover -s test -p 'test_*.py' -v
npm run verify:cycle
npm run verify:oracle
npm start
```

候補ブランチの自動検証後にmainへ統合。本番CIは**そのcommit SHA**の稼働を待ち、実推論2ターン・文脈保持・履歴・本番APIを再検証します。2026-10-04の実測では、Renderの設定表示は `autoDeploy=yes` でもmain統合後にDeployが開始されず、既存連携から手動Deployして完了しました。自動Deploy連携の根本原因は未確認です。今後のコード公開時も、設定表示だけでなくDeploy開始とコミット一致を確認してください。普段の会話利用にはDeploy操作は不要です。

`/health` はビルドの生存確認であり、外部モデルの成功保証ではありません。`/api/project/status` は統合研究状態。`/lab` は既存の限定コード実験。旧有料API経路は削除しました。

**Completion Status: EXPERIMENTAL / PARTIAL。** 無限進化・永久稼働・エラーゼロ・RSI・全体完成は実証していません。監査内容は `docs/AUDIT_CORE08.md` を参照してください。

## 会話に反映する研究

`evolution/` は、検証済みの回答補助能力を `dialogue/active.json` から実会話へ継承します。独立比較で採用された世代だけが有効になります。世代・実際の反映状態は `/api/evolution/status` と回答後の画面で確認できます。最初の範囲は整数計算・長さ換算で、モデル重みの学習や汎用知能の向上とは区別します。固定評価・採用条件・失敗時の扱いは `docs/CHAT_EVOLUTION.md` を参照してください。
